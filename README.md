# Phishing Email Analysis – SOC Investigation Project

## Overview
This repository contains a technical investigation of a suspicious email identified as a phishing attempt. 
The analysis follows a structured SOC-style workflow including email header examination, authentication 
validation, sender IP reputation checks, and malicious URL investigation.

## Objectives
- Detect phishing indicators in real-world emails
- Analyze SPF, DKIM, and DMARC failures
- Identify suspicious sender infrastructure
- Understand attacker techniques used in email-based social engineering

## Tools Used
- VirusTotal
- AbuseIPDB
- MXToolbox
- urlscan.io
- Browserling
- DNS utilities (nslookup)

## Skills Demonstrated
- Email header analysis
- Threat intelligence correlation
- Phishing detection techniques
- Cybersecurity reporting

## Final Verdict
The email was confirmed as **malicious phishing** based on multiple technical indicators.

> This project is intended for educational and academic purposes.
